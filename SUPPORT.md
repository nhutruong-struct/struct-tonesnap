# Getting help

- **Questions, setup problems, "how do I…":** ask in
  [Discussions → Q&A](https://github.com/nhutruong-struct/struct-tonesnap/discussions/categories/q-a).
  Search first; someone may have asked already.
- **Ideas and feature requests:** start in
  [Discussions → Ideas](https://github.com/nhutruong-struct/struct-tonesnap/discussions/categories/ideas).
- **Bugs:** open a [bug report](https://github.com/nhutruong-struct/struct-tonesnap/issues/new?template=bug_report.yml).
- **An app where ToneSnap cannot read or replace the selection:** open an
  [app compatibility report](https://github.com/nhutruong-struct/struct-tonesnap/issues/new?template=app_compatibility.yml).
- **Security problems:** see [SECURITY.md](SECURITY.md).

You can write in English or Vietnamese. ToneSnap is maintained by volunteers in their spare time, so please be
patient. Never post your API key, and remove private text from screenshots before you share them.
