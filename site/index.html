Say it in the right tone, in any app.

Select a sentence in Slack, Outlook, Teams or your browser, click the small icon that appears next to it (or press Ctrl+Alt+E), and ToneSnap suggests versions in several tones, in Vietnamese, English or Japanese. Click Apply and it replaces your text in place.

Everything happens where you write

No copying into a chat window and back. ToneSnap comes to the text.

⌨

Works in any app

Reads the selection with UI Automation, falls back to the clipboard and to on-device OCR. Your clipboard is always restored.

🎚

Translate or rewrite

Vietnamese, English or Japanese, in concise, natural or formal tone. Translate stays close to the original; rewrite rephrases it.

↩

Apply in place

One click (or a number key) replaces the selection in the original app. Copy when it is read-only.

✦

Hotkey or floating icon

Click the small icon that appears next to your selection, or press Ctrl+Alt+E. Prefer the hotkey alone? Switch in Settings.

🌐

Bilingual interface

Vietnamese and English, light and dark, follows Windows. Lives quietly in the tray.

⟳

Updates itself

New versions download in the background and install while you are not using ToneSnap, or choose Ask before updating. Every update is signed and verified first.

Private by design

ToneSnap reads text from other apps, so it is careful with it.

  • Sensitive data is redacted before sending: emails, phone numbers, IDs, card numbers, URLs, API keys and your own list of terms. It is restored only on your screen.
  • Password fields and blocked apps are never read (password managers are blocked by default).
  • Nothing is logged or stored. No telemetry, no account, no server of ours.
  • Screenshots never leave the device: OCR runs locally with Windows' own engine.
  • Your API key stays in Windows Credential Manager, never in a file.
  • Preview mode shows exactly what will be sent before anything is sent.
  • The only other request is the update check, to GitHub, and it sends nothing but the app version and platform.

Get started

Download the Windows installer from the latest release, or build ToneSnap from source in a few minutes.

  1. Install

    Run the x64-setup.exe installer from the latest release. The installer is not code-signed yet, so SmartScreen asks first: choose More info → Run anyway.

  2. Add an API key

    Open Settings from the tray and pick a provider; Get Key opens its key page. Google Gemini and Groq have free tiers; OpenRouter has free models; the Claude API is paid.

  3. Select and snap

    Select text in any app and click the ToneSnap icon (or press Ctrl+Alt+E). Pick the language and Translate or Rewrite right in the popup.

Build from source

Needs Rust (MSVC) with Visual Studio Build Tools, Node.js 20+ and pnpm. 

git clone https://github.com/nhutruong-struct/struct-tonesnap.git
cd struct-tonesnap
pnpm install
pwsh -File dev.ps1

To uninstall, quit ToneSnap from the tray, then remove it in Settings → Apps → Installed apps. Tick “Delete the application data” to also remove your settings and API keys. What may stay behind
